## What the device ran and what it could not

213 tests, in one run each of four shaders.  Every geometry-stage test failed to make a
pipeline: this driver's pipeline creation with a geometry stage is refused here, so those
28 tests are not in the fit.  `frag_dadd` and `vert_dadd` are absent for the same reason
fp64 is missing from the model: the GPU has no fp64.  The subgroup tests measure the
SPIR-V subgroup operations the driver emulates (a shuffle is 166x fadd, a reduction 31x),
which is real cost but no instruction of the model's classes.  The vertex tests separate
too little: their steps run in a 64-wide quad per invocation, so their intervals swallow
the difference and several came out negative; the model's classes come from the compute and
fragment primaries, and the vertex tests are kept for the next run with more unroll.

The fit predicts tests it did not use: `isub` (iadd only) 1.87, `and_add` (logic and iadd)
3.70, `not_add` 3.72, each equal to the predicted cost within its interval.
